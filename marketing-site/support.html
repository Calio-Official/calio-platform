Install

  • Chrome Web Store: use the Add to Chrome button on the home page after publish.
  • Developer mode: chrome://extensions → Enable Developer mode → Load unpacked → select the CALIO_MVP folder.

“Extension context invalidated”

Reload the extension on chrome://extensions, then hard-refresh the SEC/EDGAR tab. The content script reconnects after a reload.

Extract looks incomplete

Check the quality badge on the extract. Some forms need the primary document (or XML sibling for ownership/insider). Try Open & extract again after the filing finishes loading.

SEC rate limits

CALIO paces requests and enforces monthly/hourly extract limits to respect SEC fair-access guidance. Wait a moment and retry if EDGAR is slow or returns errors.

Not investment advice

CALIO helps you review public filings. Always verify critical figures against the original SEC document.
