How to export SEC filings to Excel

Updated July 2026 · ~6 min read · Public EDGAR workflows

Analysts and investors often need SEC filing data in Excel for models, comps, and notes. The SEC publishes structured data, but the path from an EDGAR HTML page to a clean workbook is not always obvious — especially after Interactive Data UI changes.

Option 1 — Financial_Report.xlsx in the filing folder

Many 10-K and 10-Q submissions include a workbook in the filing’s archive directory (often named something like Financial_Report.xlsx). You reach it by opening the submission folder under the company CIK on sec.gov Archives, not only from the pretty “Interactive Data” viewer.

  • Best for: standard financial statements when the file exists.
  • Limitation: not every form type; navigation is easy to get wrong; not form-aware notes.

Option 2 — Companyfacts / XBRL APIs

The SEC’s data.sec.gov companyfacts endpoints expose tagged numbers. Great for bulk work if you code. Harder if you only want one company’s latest 8-K event or a Form 4 trade table in a sheet today.

Option 3 — CALIO extract → multi-sheet Excel

CALIO is a Chrome extension that runs next to EDGAR. You open a company or filing, run Open & extract, then export a multi-sheet workbook for that extract or a period compare.

  • Works across form packs: 10-K/Q financials, 8-K events, Form 4, ownership, Form 144.
  • Compare two periods and export structured rows.
  • Processing stays on your device; no CALIO filing server.

Step-by-step with CALIO

  1. Install the extension and pin it in Chrome.
  2. Search a ticker or open a company on EDGAR.
  3. Open the filing you care about (or use Open & extract from the desk).
  4. Review the extract and quality badge.
  5. Export Excel — multi-sheet when the pack has multiple tables.

Tips for cleaner sheets

  • Prefer the primary document when extracts look sparse.
  • For insider forms, use Form 4 packs — do not expect income-statement fields.
  • Always spot-check material numbers against the original filing.
  • Respect SEC fair-access pacing; avoid hammering EDGAR with scripts.
